# ForestWatch — Система моніторингу лісів та раннього виявлення пожеж

## 📌 Опис проєкту

ForestWatch — це вебзастосунок для моніторингу лісових територій, обліку потенційних загроз і пожеж, організації перевірок за допомогою безпілотних літальних апаратів (БПЛА) та інформаційної підтримки реагування на лісові пожежі.

Проєкт поєднує бекенд на Python (Flask) із базою даних MS SQL Server та адаптивний вебінтерфейс на Bootstrap 5 і Leaflet, забезпечуючи повний цикл обробки даних та їх візуалізацію на карті.

## 🧱 Структура бази даних

Проєкт використовує реляційну базу даних Microsoft SQL Server.

Основні групи сутностей:

- **Users, Roles** — користувачі системи та їхні ролі;
- **ForestryUnits, ForestPlots, ForestStands, TreeSpecies** — лісові господарства, ділянки, деревостани та види дерев;
- **Cameras, ObservationTowers, CoverageZones, SignalSources** — засоби й зони моніторингу та джерела сигналів;
- **UAVs, UAVMissions** — безпілотні літальні апарати та їхні місії;
- **FireSuspicions, Fires, FireSeverityClasses, FireSuppressionStages** — підозри на пожежі, підтверджені пожежі, класи небезпеки та етапи гасіння;
- **Inspections, InspectionActs** — інспекції та акти перевірок;
- **FireResources, ResponseResources** — ресурси, пов'язані з реагуванням;
- **FireRiskAssessments** — оцінювання ризиків;
- **IllegalLogging, IllegalDumpSites** — відомості про незаконні вирубки та несанкціоновані звалища.
